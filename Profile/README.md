# K.Ö.St.V. Vindobona II im MKV zu Wien 

In dieser Organisation ist die öffentlich verfügbare Codebase für https://www.vindobona2.at (Repository: **vb-www**), https://intern.vondobona2.at (Repository: **vb-intern**) und das API-Backend für die beiden Erstgenannten (Repository: **vb-api**) enthalten. 

Zusätzlich gibt es mit dem Repository **vb-deploy** ein Hilfsmittel zum Deployment und IaC-Setup für die drei o.g. Codebases.
